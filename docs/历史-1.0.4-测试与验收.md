### 自动测试

原始输出见 `test-results.txt`，Windows 测试二进制在 Wine 下的输出见 `windows-wine-tests.txt`。

通过的测试覆盖：

- 代理 URL 格式验证和非法路径拒绝。
- 官方更新元数据域名、路径、大小、SHA-512 字段验证。
- ASAR 文件重写、零长度文件和空目录保留、重复适配拒绝。
- 本机转接代理的随机口令认证。

- Windows 静态代理规则解析与 bypass 规则。
- Windows 子进程便携环境变量。

Linux 核心测试启用了 Go race detector。Windows 测试在 Wine 中执行，不等同于真实 Windows 内核验证。原始官方 ASAR 测试在 Linux 上运行，在 Windows/Wine 测试输出中跳过。

## 实现限制

- 检测到拔盘时终止 Job 是兜底，不是对热拔盘数据安全的承诺。
- 未实现断点续传、差分更新、内置凭据保险箱或自动加密 U 盘。
- 代理转接不是网络级隔离；不支持代理扩展配置抓取，也不保证所有外部插件使用代理。
- 当前实现优先使用 PAC / 系统返回的第一个适用代理，不提供复杂代理列表的自动故障切换。
- 未来官方发行包结构、Electron 初始化流程和数据格式均可能变化，需要重新验收。
