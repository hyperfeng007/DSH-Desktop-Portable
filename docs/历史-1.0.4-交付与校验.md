## 完整包包括什么

| 文件/目录 | 用途 |
| --- | --- |
| DSH-Portable.exe | 可双击运行的 Windows x64 便携启动器 |
| tools/7z.exe、tools/7z.dll | 首次准备官方运行时所需的解包工具 |
| portable.json | 干净的默认自动代理配置，没有账号、口令或个人设置 |
| Update-DSH.cmd | 便携更新入口 |
| source/ | 完整启动器源码、资源、构建脚本和测试 |
| docs/ | 当前功能说明、测试证据及明确标记的历史审查记录 |
| LICENSE、THIRD-PARTY-NOTICES.md、许可证文件 | 许可与第三方来源说明 |
| SHA256SUMS.txt | 包内除该清单自身以外的全部文件校验值 |

**这是完整的启动器发行包，不是内置 DSH Desktop 的离线镜像。** 不包含个人 Runtime、Data、Workspace、API Key 或会话。

- 全新使用：完整解压，双击 EXE。没有桌面运行时时会自动从 DeepSeek 官方下载、校验并准备。
- 已有同一官方构建：按本版规则复用本地运行时，不因为便携适配版本变化就重复下载安装包。
- 用户当前已正常使用 1.0.4：无需再次升级，可以继续用现有目录。本 ZIP 用于留存或全新部署。
- 不要将默认 portable.json 覆盖到已正常使用的个人配置上。

## 旧版本清理范围

本次整理后，工作区仅保留 1.0.4 的完整源码目录、ZIP 与外部校验文件作为 DSH 交付；1.0.0、1.0.1、1.0.2、1.0.3 的独立交付目录、ZIP、外部校验文件已删除。

`source/legacy/` 内的少量已知旧适配模块，以及测试 fixture/历史测试记录，**不是可运行的旧版产品包**。它们用于识别旧运行时、支持免下载升级和回归验证，必须保留。删除它们会破坏完整源码的构建或测试能力。

清理仅针对本工作区的旧交付，不会访问或删除用户电脑/U 盘上的程序、Runtime、会话、代理配置或历史回退目录。

## 校验方法

下载 ZIP 旁的同名 `.sha256` 文件，可在 PowerShell 执行：

```powershell
Get-FileHash .\DSH-Portable-Windows-x64-v1.0.4.zip -Algorithm SHA256
```

解压后也可以核对启动器：

```powershell
Get-FileHash .\DSH-Portable\DSH-Portable.exe -Algorithm SHA256
```

应与本文 EXE 校验值一致。外部 ZIP 校验值以本次重新打包生成的 `.zip.sha256` 为准，不要拿旧整理前 ZIP 的校验值来比对新 ZIP。
